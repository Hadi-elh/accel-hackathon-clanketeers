Methodology

Ground truth is human-labelled. Each label answers one question: does this official publication describe activity matching the company's configured monitoring profile? Labels are binary (relevant / irrelevant); hard cases carry a separate borderline flag rather than a third class. Evidence is judged by normalized containment in the source text. The test set is deliberately enriched with relevant and hard cases, so its composition does not represent a normal day's stream; production cost and escalation figures come from real daily scans, not from this set. Model confidence is used internally for routing and is never shown to users.
